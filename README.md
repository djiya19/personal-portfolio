## Project Description

This project is a responsive personal portfolio website developed as part of the Web Application and Mobile Development (WAMD) module. It presents my profile, technical skills, projects, education, professional experience, and contact information.

## Technologies Used

* **HTML5:** Structure and semantic elements
* **CSS3:** Styling, layout, and responsive design
* **JavaScript:** Interactivity and DOM manipulation

## Implemented Features

* Personal introduction and About section
* Technical skills presentation
* Projects showcase
* Education and experience timeline
* Contact form with input validation
* Responsive layout for desktop, tablet, and smartphone
* Interactive navigation and Back to Top button

## Project Structure

* `index.html` — Main webpage
* `css/style.css` — Styles and responsive layout
* `js/script.js` — JavaScript interactions
* `images/` — Website images

## How to Run

1. Clone or download this repository.
2. Open `index.html` in a web browser.
